# Stonks

Who said sentiment analysis needs to be boring? 😅

[Live link](https://usestonks.vercel.app)

## Running locally

1. Clone or download the repository
2. Set the environment variables (Get yours by registering on [finnhub](https://finnhub.io/))
3. Start the app with `npm run dev`
